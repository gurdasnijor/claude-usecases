# Technical Writer

> Professional documentation for APIs, code, and developer experiences

## Overview

The Technical Writer skill creates clear, comprehensive technical documentation. It transforms code and specifications into accessible documentation for developers, users, and stakeholders.

## When to Use

- **API documentation** - Endpoint references, schemas, auth guides
- **README files** - Project overviews, installation, quick starts
- **User guides** - Getting started, tutorials, troubleshooting
- **Integration guides** - Setup, configuration, best practices
- **Changelogs** - Release notes, migration guides

## Documentation Types

| Type | Purpose | Audience |
|------|---------|----------|
| **API Reference** | Complete endpoint documentation | Developers |
| **README** | Project overview and quick start | All users |
| **User Guide** | Feature tutorials and how-tos | End users |
| **Integration Guide** | Third-party setup instructions | Developers |
| **Changelog** | Version history and updates | All users |

## Quick Examples

### Generate README
```
Create a README for this Python library:
[paste code or describe project]
```

### Document API
```
Document this REST API endpoint:
POST /api/users
Creates a new user. Requires email and name.
Returns user object with ID.
```

### Write User Guide
```
Write a getting started guide for [product].
Target audience: [describe users]
Key tasks: [list main tasks]
```

## Output Structure

### API Reference
- Endpoint description
- Request/response schemas
- Parameters table
- Code examples (curl, language SDKs)
- Error codes

### README
- Project name + description
- Features
- Installation
- Quick start example
- Configuration
- API reference link
- Contributing + License

### User Guide
- Prerequisites checklist
- Step-by-step instructions
- Screenshots/examples
- Troubleshooting
- Next steps

## Writing Standards

| Standard | Guideline |
|----------|-----------|
| **Voice** | Active, direct |
| **Tone** | Professional, helpful |
| **Person** | Second person ("you") |
| **Tense** | Present tense |
| **Examples** | Complete, copy-paste ready |
